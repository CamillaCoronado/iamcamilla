privacy policy — iamcamilla | pinterest reference

effective date: october 8, 2026

company / app operator: iamcamilla

pinterest reference is a personal-use chatgpt plugin intended to help its user analyze pinterest boards and pins for visual inspiration, moodboards, and room design.

current status

the plugin currently works with pinterest links and images the user provides. pinterest account sign-in and api access are not yet implemented. this policy will be updated before any authenticated pinterest connection is enabled.

information used

the plugin may process pinterest board and pin urls, publicly accessible pin images and descriptions, and reference images voluntarily provided in a chat. when a future pinterest integration is authorized, it is intended to request only read permissions for boards and pins. it will not request the user's pinterest password.

purposes

information is used only to inspect and summarize design references, identify aesthetic preferences, and produce requested moodboards or design recommendations.

storage and sharing

this plugin currently has no separate database or independent data collection service. information shared with chatgpt is handled by openai under its applicable terms and privacy policy. pinterest pages and data remain subject to pinterest's policies. the plugin operator does not sell pinterest data or use it for advertising.

a future authenticated integration may require securely storing oauth tokens to maintain authorized access; any such implementation and its retention and deletion rules will be disclosed here before launch.

user control

users can stop providing links or images at any time. if authenticated access is introduced, users will be able to revoke it through pinterest's authorized-app settings. requests about data handled by chatgpt are governed by openai's privacy controls.

contact

for questions about this personal-use plugin or this policy, open an issue at https://github.com/CamillaCoronado/iamcamilla/issues.

changes

this policy may change when new capabilities are implemented. the effective date will be updated to reflect material changes.
